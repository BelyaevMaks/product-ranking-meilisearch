# Локальные данные (не в Git)

Сюда кладутся файлы, которые ожидает `pipeline/config.py`:

| Файл / папка | Назначение |
|--------------|------------|
| `shop_data-10.04.2026 2.csv` | Выгрузка каталога (варианты). Имя зашито в `PipelineConfig.shop_catalog_path` — при новой дате обновите путь в `pipeline/config.py`. |
| `categories.csv` | Справочник категорий (сейчас загружается, но в расчёт `category_name` товара почти не используется). |
| `customers-actions-new/` | JSON-действия Mindbox (просмотры, корзина, покупки). |

Папка в `.gitignore`, чтобы не коммитить персональные и коммерческие данные. Для CI или демо используйте обезличенные сэмплы в отдельном приватном хранилище.
